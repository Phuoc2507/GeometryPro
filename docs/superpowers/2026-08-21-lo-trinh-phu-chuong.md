# Lộ trình phủ chương Lý – Hóa lớp 10–12 (cập nhật đêm 21/08/2026)

> Nguyên tắc bất biến: MỌI chương đều đi qua dây chuyền
> **spec (có bài mẫu tính tay) → phản biện chuyên môn → sửa → code TDD → phản biện code**.
> Không chương nào được code tắt — vòng phản biện đầu tiên đã chứng minh spec
> chưa soi là spec có bom (4 record Hóa suýt trả đáp sai có "con dấu kiểm chứng").

## Ghi chú ưu tiên

- Đợt 4 chưa giao đêm nay có chủ đích: 6 spec đợt 2+3 đã đủ tải cho vòng phản
  biện kế tiếp; giao thêm nữa là vượt băng thông kiểm soát chất lượng.
- Thứ tự code sau v0: theo tần suất xuất hiện trong đề thi + độ chín của spec
  sau phản biện — quyết vào sáng 22/08 cùng người dùng.
- Các chương "nặng lý thuyết nhẹ tính" (polymer, carbohydrate) có thể hợp mô
  hình DB-tra-cứu + câu lý thuyết hơn là engine tính — cần thiết kế riêng,
  không ép vào khuôn stoichiometry.
